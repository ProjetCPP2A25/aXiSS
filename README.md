# AXIS — Employés et interventions

Cette version conserve les modules **Gestion des employés** et **Gestion des interventions**.
Les fichiers sources des modules **Véhicules** et **Matériels** ont été retirés du projet.

## Ouvrir le projet
1. Décompresser l’archive.
2. Ouvrir `AXIS.pro` dans Qt Creator.
3. Choisir un kit Qt avec Widgets, Network et SQL.
4. Lancer qmake, puis reconstruire le projet.

La compilation n’a pas pu être testée dans cet environnement : vérifiez le build dans Qt Creator.
